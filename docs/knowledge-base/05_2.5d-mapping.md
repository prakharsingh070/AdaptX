# 2.5D Mapping

## Definition

ADAPT-X uses a 2.5D spatial representation: `x` and `y` identify a spatial cell while `z` is summarized as height information rather than representing a full volumetric 3D grid.

## Cell Fields

A map cell may contain:

- occupancy probability
- height or height range
- point count
- confidence
- risk
- resolution
- timestamp

The exact schema is defined in `17_data-schema.md` and must remain consistent across backend, benchmark, and dashboard code.

## Requirements

The mapper must document its coordinate frame, cell bounds, resolution units, update policy, temporal behavior, missing-data behavior, and handling of dynamic objects. Adaptive maps must make resolution changes observable and attributable to risk or uncertainty inputs.
