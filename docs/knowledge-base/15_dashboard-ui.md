# Dashboard UI

## Purpose

The dashboard is an operational and explanatory interface, not a decorative mockup. Visualizations should correspond to real backend state whenever possible.

## Header

Display ADAPT-X, the subtitle Adaptive Dynamic Perception and Tracking, system status, CARLA connection status, and controls for CARLA Simulator, Scenario Manager, and Settings.

## Data Rule

Avoid hardcoded fake values in production or demo logic. When live data is unavailable, clearly label simulation, replay, or unavailable states.
